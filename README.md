# 🌐 DAON Browser Agent

**DAON Agent System 전용 크롬 사이드 패널 비서 & 브라우저 자동 조작 확장 프로그램**

평소 쓰시던 구글 크롬 브라우저 우측에 DAON을 항상 띄워두고 대화하며,
**"현재 보고 있는 페이지 요약/분석"**부터 **"실제 웹페이지 타이핑 & 마우스 클릭 제어"**까지 수행합니다.

> ⚠️ 이 확장은 **DAON Agent System 데스크톱 앱**과 함께 사용하는 클라이언트입니다.
> 다온 앱 없이 단독으로는 동작하지 않습니다. (`127.0.0.1:9090`)

## 🚀 30초 설치 가이드 (크롬 브라우저)

1. **위 Releases에서 `daon-browser-agent.zip`을 내려받아 압축을 풉니다.**
   (압축을 풀면 `daon-browser-agent` 폴더가 나옵니다. 이 폴더를 지우지 말고 그대로 두세요.)
2. **Google Chrome** 브라우저를 엽니다.
3. 주소창에 `chrome://extensions/` 를 입력하고 이동합니다.
4. 우측 상단의 **[개발자 모드 (Developer mode)]** 토글 스위치를 켭니다.
5. 좌측 상단 **[압축해제된 확장 프로그램을 로드합니다]** (Load unpacked) 버튼을 클릭합니다.
6. **1번에서 압축을 푼 `daon-browser-agent` 폴더를 선택합니다.**
7. 크롬 툴바 우측 상단 퍼즐 조각(확장 프로그램) 아이콘을 누르고, **DAON Browser Agent**의 핀(📌)을 눌러 고정합니다.

> 💡 git으로 받으신 경우에는 clone한 `daon-browser-agent` 폴더 자체를 6번에서 선택하면 됩니다.

## 🎯 사용 방법

1. **사이드 패널 열기**
   - 크롬 툴바의 **DAON 아이콘**을 클릭하거나, 단축키 `Alt + D`를 누르면 브라우저 우측에 다온 사이드 패널이 바로 열립니다.
2. **연결 상태 확인**
   - 상단 배지에 `🟢 연결됨: 9090`이 표시되면 로컬 다온 앱(`server.py`)과 정상 통신 중입니다.
   - 연결이 안 되면 다온 데스크톱 앱이 실행 중인지 먼저 확인하세요.
3. **현재 페이지 분석 (Sensor)**
   - 기사, 유튜브, 깃허브 등 아무 웹페이지를 보고 있을 때 **[📌 탭 컨텍스트 첨부]** 버튼 또는 **[📄 이 페이지 요약]** 퀵 버튼을 누르면, 복사/붙여넣기 없이 다온이 현재 페이지 내용을 즉시 읽고 답변합니다.
4. **웹페이지 직접 조작 (Actuator)**
   - *"검색창에 '아이폰 16' 입력해줘"*
   - *"제출 버튼 눌러줘"*
   - *"화면 아래로 스크롤 내려줘"*

   라고 지시하면, 확장이 실제 웹페이지의 DOM 요소를 찾아 **부드러운 하이라이트 효과와 함께 실제 클릭 및 React/Vue 호환 타이핑**을 대신 수행합니다.

## 🛠️ 주요 특징

- **초경량 0ms 로컬 직통 연결** — 외부 클라우드 중계 없이 내 컴퓨터(`127.0.0.1:9090`)와 직접 통신하여 지연 시간이 없습니다.
- **개인정보 보호** — 브라우징 내역과 웹페이지 데이터가 외부로 나가지 않고 오직 내 로컬 PC 안에서만 처리됩니다.
- **마우스 커서 자유** — 좌표 클릭이 아닌 내부 DOM 합성 이벤트로 작동하므로, 다온이 타이핑하고 클릭하는 중에도 사용자는 마우스로 자유롭게 다른 작업을 할 수 있습니다.
- **React/Vue 제어 컴포넌트 호환** — 최신 프레임워크 폼에서도 값이 정상 반영되도록 프로토타입 디스크립터 이벤트를 완벽하게 발생시킵니다.
- **표면(surface) 기반 도구 차단** — 사이드 패널 세션은 `surface: 'chrome_extension'`을 선언해, 내부 브라우저 도구(`browser_*`)가 애초에 도구 목록에서 제거됩니다. 다온이 자기 자신의 브라우저를 조작하려는 혼선이 구조적으로 차단됩니다.
- **스테일 클릭 차단 (nodeId + guard)** — 스냅샷이 각 요소에 `nodeId`를 부여하고, 실행 직전에 역할·이름·값·체크상태·비활성 여부를 재검증한 뒤 클릭합니다. 스냅샷 이후 페이지가 바뀌었으면 **실행을 거부**하므로 엉뚱한 요소를 조작하지 않습니다. 가려짐(오버레이)까지 hit-test로 검사합니다.

## 🆕 변경 이력

### v1.1.1 (2026-09-19)

**iframe 내부 요소 좌표계 버그 수정**

- `iframe` 안의 요소를 조작할 때 **좌표계 불일치로 "가려짐(covered)"으로 오판해 실행이 거부되던 문제**를 수정했습니다.
  (`getBoundingClientRect()`는 프레임 기준인데 `elementFromPoint()`는 문서 기준이라 비교가 성립하지 않았습니다.)
- `iframe` 내부 요소의 가시성 판정을 **그 프레임의 뷰 기준**으로 계산하도록 수정했습니다.
- 결과: `iframe` 내부 버튼 클릭·입력이 정상 동작하면서, 스테일 검증은 그대로 유지됩니다.

### v1.1.0 (2026-09-19)

**요소 지정 방식 개편 — 스테일 클릭 차단**

- 스냅샷 출력에 `nodeId` 추가: `[#3|nodeId=7] <button> "검색"`
- 클릭/호버/입력 시 `nodeId` 로 요소를 지정하면 **스냅샷 시점과 동일한 요소가 보장**됩니다.
  ```html
  <daon_action action="click" nodeId="7" />
  <daon_action action="type" nodeId="3" text="검색어" />
  ```
- 실행 직전 6종 검증: 요소 소실 / DOM 이탈 / 숨김 / 상태 변경 / 읽기 불가 / 오버레이 가림
- 페이지가 바뀌면 실행이 거부되고 `[⚠️ 페이지 변경 감지 — 재스냅샷 필요]` 안내가 표시됩니다.
- 관측 한도 50 → **250개**, 뷰포트 밖·비활성·password/file 요소 자동 제외
- `target=` (CSS 셀렉터) 방식도 **그대로 동작**합니다 (하위 호환).

> 출처: [browser-use/jev-ultrafast](https://github.com/browser-use/jev-ultrafast) (MIT) 의
> `name()`/`role()`/`guard()` 및 실행 직전 기하 재해석 + hit-test 설계를 이식했습니다.

### v1.0.0 (2026-09-16)

- 최초 릴리스 — 사이드 패널 대화, 페이지 요약/분석, DOM 클릭·타이핑 조작, 표면 기반 도구 차단

## 🧩 구성 파일

| 파일 | 역할 |
|---|---|
| `manifest.json` | MV3 매니페스트 (권한·사이드패널·단축키 정의) |
| `background.js` | 서비스 워커 (사이드패널 토글) |
| `sidepanel.html` / `sidepanel.css` / `sidepanel.js` | 다온 대화 사이드 패널 UI + 서버 통신 |
| `content.js` / `content.css` | 페이지 DOM 탐색·조작, 하이라이트 오버레이, 인터랙션 로거 |
| `icons/` | 툴바 아이콘 (16/48/128) |

## 🔧 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 배지가 `🔴 연결 안 됨` | 다온 데스크톱 앱이 실행 중인가? (`http://127.0.0.1:9090` 접속 확인) |
| 확장이 크롬 목록에 안 보임 | `chrome://extensions/` 에서 개발자 모드가 켜져 있는지 확인 |
| 페이지 조작이 안 됨 | 해당 탭을 새로고침 (content script는 페이지 로드 시 주입됩니다) |
| `⚠️ 페이지 변경 감지` 가 뜸 | **정상 동작입니다.** 스냅샷 이후 페이지가 바뀌어 조작을 거부한 것입니다. 다시 스냅샷을 찍으면 새 `nodeId`가 발급되니 그 값으로 다시 지시하세요. |
| 아이콘이 회색/깨짐 | 압축을 푼 폴더에서 파일이 빠지지 않았는지 확인 후 다시 로드 |
