CHROME SIDE PANEL EXTENSION

보고 있는 페이지를,
직접 조작합니다.

DAON Browser Agent는 크롬 우측 사이드 패널에 다온을 상주시킵니다. 페이지 요약·분석부터 검색창 타이핑, 버튼 클릭, 스크롤까지 — 로그인된 실제 웹 환경에서 그대로 실행합니다.

확장 프로그램 받기 v1.1.5 · ZIP 설치 방법 보기
Chrome · Brave · Edge  /  Manifest V3  /  MIT License
⚠ 선행 요구사항
이 확장은 DAON Agent System 데스크톱 앱과 함께 사용하는 클라이언트입니다. 단독으로는 동작하지 않으며, 다온 앱이 127.0.0.1:9090 에서 실행 중이어야 합니다.
01

설치 (30초)

  1. 위 「확장 프로그램 받기」 버튼으로 ZIP을 내려받아 압축을 풉니다. (압축을 풀면 daon-browser-agent 폴더가 나옵니다 — 지우지 마세요.)
  2. Google Chrome 을 엽니다.
  3. 주소창에 chrome://extensions/ 를 입력해 이동합니다.
  4. 우측 상단 [개발자 모드] 토글을 켭니다.
  5. 좌측 상단 [압축해제된 확장 프로그램을 로드합니다] 를 눌러 방금 푼 daon-browser-agent 폴더를 선택합니다.
  6. 툴바 퍼즐 아이콘 → DAON Browser Agent 핀(📌)을 눌러 고정합니다.
02

무엇을 하나요

📄 페이지 읽기

[탭 컨텍스트 첨부] 한 번으로 복사·붙여넣기 없이 현재 페이지를 즉시 읽고 요약합니다.

⌨️ 직접 타이핑

검색창·폼 입력을 사람 리듬(25~65ms)으로 입력해 봇 감지를 회피합니다.

🖱️ 요소 클릭

스냅샷으로 잡은 정확한 요소만 누릅니다. 페이지가 바뀌면 실행을 자동 거부합니다.

🔒 격리 제어

ActiveTab 권한 기반 — 필요한 탭에서만 동작하고 나머지는 건드리지 않습니다.

04

문제 해결

증상 해결
사이드 패널이 안 열림 chrome://extensions/ 에서 확장이 켜짐 상태인지 확인 후, 툴바 아이콘을 클릭하세요.
연결이 안 됨 (🔴) 다온 데스크톱 앱이 실행 중인지 확인하세요. 앱 기동까지 최대 1분 걸릴 수 있습니다.
엉뚱한 요소를 클릭함 페이지가 바뀐 뒤 옛 스냅샷을 쓴 경우입니다. 다시 스냅샷을 찍으면 최신 요소로 갱신됩니다.
업데이트 방법 새 ZIP으로 폴더를 교체한 뒤 chrome://extensions/ 에서 새로고침(⟳) 을 누르세요.
